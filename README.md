# שביל המצווה

אתר משפחתי לליווי שנת המצווה: 56 מקטעי שביל ישראל, מהחרמון לאילת, עם הרשמה לטיולים, שביל צעיר, שגרירי מקטע ומפת התקדמות.

- **צד משתמש:** React + Vite + Tailwind, עברית RTL, קודם כל לטלפון.
- **נתונים, כניסה והרשאות:** Supabase. הכניסה בקישור למייל, ורק מי שברשימת `invitations`.
- **אחסון:** Vercel. כל דחיפה ל־`main` עולה לאתר; כל ענף מקבל כתובת תצוגה מקדימה.

## מבנה

| תיקייה | מה יש בה |
| --- | --- |
| `supabase/migrations/` | מבנה הטבלאות והרשאות (RLS). כל חוק אבטחה נאכף במסד הנתונים, לא רק במסך |
| `supabase/seed.sql` | הנתונים שיובאו מ־Base44 |
| `scripts/import_base44.py` | ממיר את קובצי ה־CSV של Base44 ל־`seed.sql` |
| `src/lib/rules.ts` | חוקי האתר (חלון הרשמה, קושי, מרחק, התקדמות, תכנון יום), עם בדיקות ב־`__tests__` |
| `src/pages/` | המסכים |

## פיתוח

```
npm install
npm run dev     # http://localhost:5173
npm test        # בדיקות החוקים
npm run build
```
